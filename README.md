# biubiu

Cursor 多窗口任务进度监测工具

## ✨ 功能简介

专门面向 Cursor 编辑器用户开发的桌面托盘工具：

- 自动识别打开的多个 Cursor 窗口，抓取正在执行的任务信息，点击切换到对应的 Cursor 窗口；
- 卡片式列表展示每个任务的实时进度，任务结束后高亮绿色标记完成状态。
- 常驻后台、低资源占用，不用来回切换窗口查看 AI 任务进度。

## 💡 说明

第一次运行时会自动在 Cursor 安装 hook 插件用于检测。

仅本地监测，不会上传你的代码、对话内容到第三方服务器。
