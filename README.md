# biubiu

Cursor 多窗口任务进度监测工具

<img src="assets/biubiu-img.png" width="96" alt="biubiu">

## ✨ 功能简介

专门面向 Cursor 编辑器用户开发的桌面托盘工具：

- 自动识别打开的多个 Cursor 窗口，抓取正在执行的任务信息；
- 卡片式列表展示每个任务的实时进度，任务结束后高亮绿色标记完成状态。
- 常驻后台、低资源占用，不用来回切换窗口查看 AI 任务进度。
